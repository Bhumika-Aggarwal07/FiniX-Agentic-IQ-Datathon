# One-minute demo guide

1. **Frame the objective** — FiniX makes disconnected transaction, chargeback, KYC, and merchant evidence reviewable without fabricating a fraud label.
2. **Show executive scale** — Point to transaction volume, disputed value, and investigation queues.
3. **Show the linkage finding** — In Chargeback intelligence, filter to identity mismatch. Explain that FiniX links by transaction ID but preserves the original chargeback identities.
4. **Show denominators** — In Merchant risk, set a minimum transaction volume and compare raw chargeback counts with the protected relationship metric.
5. **Show graph value** — In Risk network, select a user or merchant. Explain grey observed transaction edges and red risk-signal edges.
6. **Show agentic safety** — In Investigation explorer, ask `Why is USR35882 an investigation candidate?`; the response cites generated facts and ends with the limitation that data does not establish fraud.
7. **Close with assurance** — Open Data quality, showing source duplication, parsing, coverage, mismatch, and network calculations.
